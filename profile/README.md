# Numeron

**Regulatory intelligence infrastructure for global finance.**

Numeron turns authoritative tax rules into versioned knowledge graphs, deterministic computation APIs, and authority-linked audit traces.

```
Source → Knowledge Graph → Executable Logic → Deterministic Computation → Audit Trace
```

## Products

- **NumeronTax**: tax preparation for digital banks and fintechs, built on the Numeron platform.
- **[Zurdo](https://zurdo.sh)**: the zurdo CLI.
